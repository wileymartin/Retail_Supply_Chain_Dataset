# Retail_Supply_Chain_Dataset

## OVERVIEW
Analyzing retail orders,sales performance, customer details, and shipment logistics from a public dataset published in Kaggle

## Analysis 
The analysis focuses on: 
- Customer profit margins
- Product profit margins
- Region profitability
- Product delivery times
- Transportation modes
  
- ## Tools Used
- SQL via duckdb extension (PostgreSQL was not installed on my laptop due to admin privileges not available)
- Jupyter notebook
- Pandas

  ## Dataset
  - This dataset was obtained from Kaggle and looks at retail data described in the overview
 
  ## Project Goal
  - The goal of this project was to break the data out into groups and develop insights from these different segments. We looked at trends in customers, products, and regions and their relationship to profitability for this retail store.
